# E-Commerce Sales Analysis | Excel & Power BI

## Project Overview

This project focuses on analyzing e-commerce sales data through data cleaning, transformation, and visualization to generate meaningful business insights.

I started with a raw and uncleaned e-commerce dataset containing 300 records and 13 columns. I used Microsoft Excel Power Query to clean and transform the data. After completing the cleaning process, I imported the cleaned dataset into Power BI and developed an interactive sales dashboard to analyze revenue, orders, product performance, and sales trends.

## Tools & Technologies

- Microsoft Excel
- Power Query
- Microsoft Power BI

## Project Workflow

### 1. Data Collection
- Collected a raw and uncleaned e-commerce sales dataset.
- Worked with 300 records and 13 columns.

### 2. Data Cleaning & Transformation (Excel Power Query)
- Imported the raw CSV dataset into Excel Power Query.
- Identified and handled data quality issues.
- Standardized inconsistent values and formats.
- Corrected date formats and checked data types.
- Prepared the cleaned dataset for analysis.

### 3. Dashboard Development (Power BI)
- Imported the cleaned Excel dataset into Power BI.
- Created KPI cards to track key business metrics.
- Developed interactive charts to analyze sales performance.
- Added slicers to enable dynamic filtering.

## Dashboard Features

The dashboard includes:

- **Total Revenue:** Overall revenue generated.
- **Total Orders:** Total number of orders.
- **Delivered Orders:** Number of successfully delivered orders.
- **Average Order Value:** Average revenue per order.
- **Return Rate:** Percentage of returned orders.
- **Cancellation Rate:** Percentage of cancelled orders.
- **Monthly Revenue Trend:** Monthly revenue performance.
- **Order Status Distribution:** Breakdown of order statuses.
- **Sales by Category:** Revenue contribution by product category.
- **Top 5 Products by Revenue:** Highest revenue-generating products.
- **Revenue by City:** City-wise revenue comparison.

## Interactive Filters

Users can explore the dashboard using the following slicers:

- Product
- Category
- City
- Payment Method
- Order Status
